# Poke Arena 3D — Cueva Celeste

Full-screen 3D WebGL battle arena (**Charizard / Mega Charizard X vs. Mewtwo**) with:
- **1P vs CPU**, **2P Local** (split keyboard + shared voice), and **2P Online P2P** (`?room=CUEVA` over WebRTC)
- **Bilingual Voice Commands** (Español / English)
- **Dolby 3D Spatial Audio** + Official Pokémon Origins & Mewtwo Adaptive OST
- **Full-Screen** support including macOS Safari (`webkitRequestFullscreen`)

Play live: https://taquion.github.io/poke-arena-3d/
